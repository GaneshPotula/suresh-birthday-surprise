SURESH BIRTHDAY SURPRISE — COUSIN.EXE 🎂

Personalized for Suresh by Ganesh.
Built with HTML, CSS, and JavaScript. Responsive layout, animations, confetti, quiz, memory gallery, and personal letter.

HOW TO RUN
1. Extract this ZIP.
2. Open the `suresh_birthday_surprise` folder in VS Code.
3. Double-click index.html to preview, or use the Live Server extension.

ADD YOUR THREE PHOTOS
Put your photos in the `photos` folder and name them exactly:
- memory-1.jpg
- memory-2.jpg
- memory-3.jpg

If your photos are PNG or have different names, update the three src values in index.html to match those exact filenames.

PERSONALIZE
- Names are already set to Suresh and Ganesh in index.html and script.js.
- Edit the message and photo captions in index.html.
- Edit quiz questions and answers in script.js. For each question, `answer` is the zero-based index of the correct option (first option = 0).

PUBLISH FREE WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html, script.js, and the photos folder to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, select main and /(root), and save.
5. Wait for the published URL, then test it on mobile before sending it to Suresh.

IMPORTANT
The three original photos were not attached to the message I could access when creating this updated package, so the project includes clearly marked photo slots. Add your actual photos to the photos folder before publishing.
